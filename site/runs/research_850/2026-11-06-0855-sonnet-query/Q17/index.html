Which of Mara Ellison's works are not research output because of their document type?

Tests: Document types: an editorial and an erratum, under two author records.

Expected: works = ['W04', 'W05', 'W271', 'W813', 'W936', 'W949']

✅ D6 sparql+axioms run 1 graded by code · query session

W04, W05, W271, W813, W936, W949. These are editorials and errata, so they are excluded by document type. The preprints are excluded as superseded by their published versions, and W374 is retracted.

JSON: {"works": ["W04", "W05", "W271", "W813", "W936", "W949"]}

✅ D6 sparql+axioms run 2 graded by code · query session

The editorials and errata: W04, W05, W271, W813, W936, W949.
- Not counted here: preprints W02, W612 and W663, which fall away because they are versions of other works.
- Not explained by type: W07, W374, W449 and W763 are articles that are still not research works. The data doesn't show the reason.

JSON: {"works": ["W04", "W05", "W271", "W813", "W936", "W949"]}

✅ D6 sparql+axioms run 3 graded by code · query session

W04, W271 and W936 (editorials) and W05, W813 and W949 (errata). W07 is excluded for its source, not its type.

JSON: {"works": ["W04", "W05", "W271", "W813", "W936", "W949"]}

✅ D6 sparql+axioms run 4 graded by code · query session

W04, W271 and W936 are editorials; W05, W813 and W949 are errata. I did not list the preprints W02, W612 and W663, because those drop out by counting as their published versions.
