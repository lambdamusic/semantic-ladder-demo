🟡 D6 sparql+axioms run 4 graded by llm · query session

W70's credited institution is I06 only. I06 counts towards itself only, not towards I02, so W70 is not one of the University of Albury's works. The Tessel Laboratory (I04) is not among its credited institutions.

Why: Says the work is credited to I06 only, which counts only toward itself and not toward the University of Albury. It never states the last-listed-affiliation rule, and it doesn't say outright that the Halloran Institute is an affiliated institute rather than a unit.

🟡 D6 sparql+axioms run 5 graded by llm · query session

Why: Says I06 doesn't count toward I02, but never gives the rule that only the last-listed affiliation counts, and doesn't say Halloran is an affiliated institute rather than a unit.
