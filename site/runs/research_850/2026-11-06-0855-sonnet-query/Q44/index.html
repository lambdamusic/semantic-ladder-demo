Which institutions are part of the Albury University System, at any level below it?

Tests: Local type: an affiliated institute (AFF) is not a unit of its parent.

Expected: institutions = ['I02', 'I03', 'I04', 'I05', 'I19', 'I20']

✅ D6 sparql+axioms run 1 graded by code · query session

I02, I03, I04, I05, I19, I20. I06 is excluded: its parent is I02, but its derived ultimate parent is itself.

JSON: {"institutions": ["I02", "I03", "I04", "I05", "I19", "I20"]}

✅ D6 sparql+axioms run 2 graded by code · query session

I02, I03, I04, I05, I19, I20. I06 and I21 are only affiliated, with their own ultimate parent.

JSON: {"institutions": ["I02", "I03", "I04", "I05", "I19", "I20"]}

✅ D6 sparql+axioms run 3 graded by code · query session

I02, I03, I04, I05, I19 and I20. The affiliated institutes I06 and I21 are not part of the system.

JSON: {"institutions": ["I02", "I03", "I04", "I05", "I19", "I20"]}

✅ D6 sparql+axioms run 4 graded by code · query session

I02, I03, I04, I05, I19, I20.

JSON: {"institutions": ["I02", "I03", "I04", "I05", "I19", "I20"]}

✅ D6 sparql+axioms run 5 graded by code · query session

I02, I03, I04, I05, I19 and I20. I06 and I21 are not included, since their ultimate parent is themselves and they do not count towards I01.

JSON: {"institutions": ["I02", "I03", "I04", "I05", "I19", "I20"]}
