Which institutions are part of the Albury University System, at any level below it?

Tests: Local type: an affiliated institute (AFF) is not a unit of its parent.

Expected: institutions = ['I02', 'I03', 'I04', 'I05']

❌ R1 csv run 1 graded by code

I02, I03, I04, I05 and I06.

JSON: {"institutions": ["I02", "I03", "I04", "I05", "I06"]}

Why: institutions: expected ['I02', 'I03', 'I04', 'I05'], got ['I02', 'I03', 'I04', 'I05', 'I06']

❌ R1 csv run 2 graded by code

I02, I03, I04, I05, I06. **Reasoning:** I02 is directly under I01, I03 and I05 are the next level, I04 sits under I03, and I06 sits under I02.

JSON: {"institutions": ["I02", "I03", "I04", "I05", "I06"]}

Why: institutions: expected ['I02', 'I03', 'I04', 'I05'], got ['I02', 'I03', 'I04', 'I05', 'I06']

✅ R10 executed run 1 graded by code

I02, I03, I04 and I05, per the institution_units roll-up. Caveat: institutions.csv lists I06 as a child of I02, but I06 has no roll-up row, so the data is inconsistent about whether I06 is included.

JSON: {"institutions": ["I02", "I03", "I04", "I05"]}

❌ R10 executed run 2 graded by code

I02, I03, I04, I05 and I06. Parent links place them below I01. I06 is an AFF affiliation and is not in I01's unit counts, so it is included on the hierarchy alone.

JSON: {"institutions": ["I02", "I03", "I04", "I05", "I06"]}

Why: institutions: expected ['I02', 'I03', 'I04', 'I05'], got ['I02', 'I03', 'I04', 'I05', 'I06']

✅ R10 executed run 3 graded by code

I02, I03, I04 and I05. These are the institutions whose works count towards I01 in institution_units. I06 has parent I02 in institutions.csv but its works don't count towards I02 or I01, so it's excluded here; this is ambiguous.

JSON: {"institutions": ["I02", "I03", "I04", "I05"]}

❌ R10 executed run 4 graded by code

I02, I03, I04 and I05 by counting towards I01. I06 is a child of I02 in institutions.csv, but its works do not count towards I02 or I01 in institution_units. If "part of" means the parent_id hierarchy only, I06 is also included.

JSON: {"institutions": ["I02", "I03", "I04", "I05", "I06"]}

Why: institutions: expected ['I02', 'I03', 'I04', 'I05'], got ['I02', 'I03', 'I04', 'I05', 'I06']

✅ R10 executed run 5 graded by code

I02, I03, I04 and I05. These are the institutions whose institution_units rows include I01 at a level above 0. I06 has parent_id I02 in institutions.csv but no institution_units row linking it to I01, so the data is inconsistent on whether it is part of the system.
