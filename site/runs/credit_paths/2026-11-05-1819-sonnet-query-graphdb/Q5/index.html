Whose credit risk does a holder of the Northwind Finance 2030 notes take, and how is it rated?

Tests: Roles: issuer versus guarantor; a finance subsidiary's guaranteed debt carries the guarantor's risk.

Expected: risk_of = E02 rating = A

✅ D4 sparql run 1 graded by code · query session

E02, rated A. I03 is issued by E04 but guaranteed by E02, so the holder takes E02's risk. I03 is rated A (A11).

JSON: {"risk_of": "E02", "rating": "A"}

✅ D4 sparql run 2 graded by code · query session

The holder takes the guarantor E02's risk (I03 is issued by E04 and guaranteed by E02). E02 is rated A, as is the note (A10, A11).
