In which country is Halden Bank domiciled?

Tests: Local rule: where records disagree on country, the RESEARCH record holds.

Expected: country = LU

❌ R1 csv run 1 graded by code

DE. E10 (Halden Bank AG) is domiciled in DE. E17, which shares its LEI, lists LU, which conflicts.

JSON: {"country": "DE"}

Why: country: expected LU, got DE

❌ R1 csv run 2 graded by code

DE, per E10. E17 gives LU for the same LEI, so the record conflicts.

JSON: {"country": "DE"}

Why: country: expected LU, got DE

❌ R1 csv run 3 graded by code

DE. E10 is domiciled in DE, but its duplicate record E17 says LU, so the data conflicts.

JSON: {"country": "DE"}

Why: country: expected LU, got DE

❌ R1 csv run 4 graded by code

DE. E10 is domiciled in DE, but E17 with the same LEI lists LU, which is a conflict in the data.

JSON: {"country": "DE"}

Why: country: expected LU, got DE

❌ R1 csv run 5 graded by code

DE. E10 is DE, but its duplicate E17 (same LEI) records LU, so the country is contested.

JSON: {"country": "DE"}

Why: country: expected LU, got DE

LU

LU. RESEARCH (E17) holds for domicile and records LU, overriding RATINGS' DE for E10.
