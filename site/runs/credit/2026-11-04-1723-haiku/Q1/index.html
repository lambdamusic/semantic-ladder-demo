What was Kestrel Energy's rating on 1 January 2025?

Tests: Time: a rating holds from one action to the next, so 'the rating on a date' is the latest action on or before it.

Expected: rating = A-

✅ R5 csv+ontology run 1 graded by code

A-. Kestrel's FC long-term rating was set to A- by A01 (2024-03-12) and was not changed until A02 (2025-06-20) downgraded it to BBB.

JSON: {"rating": "A-"}

✅ R5 csv+ontology run 2 graded by code

A-. Kestrel's foreign-currency long-term rating was set to A- on 2024-03-12 (A01) and not changed until the downgrade to BBB on 2025-06-20 (A02).

JSON: {"rating": "A-"}

✅ R5 csv+ontology run 3 graded by code

A-. Only A01 (2024-03-12, assigned A-) precedes 2025-01-01 for E01; A02 (downgrade to BBB) came later.

JSON: {"rating": "A-"}

✅ R5 csv+ontology run 4 graded by code

JSON: {"rating": "A-"}
