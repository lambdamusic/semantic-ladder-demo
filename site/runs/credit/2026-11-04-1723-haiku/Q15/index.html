What was Halden Bank's rating on 1 January 2026?

Tests: Time: the downgrade came later in 2026.

Expected: rating = A-

✅ R5 csv+ontology run 1 graded by code

A-. A27 (BBB+) is dated 2026-04-15, after 2026-01-01, so the prior A- from A26 (2023-05-01) still applies.

JSON: {"rating": "A-"}

✅ R5 csv+ontology run 2 graded by code

A-. Halden Bank (E10, incl. E17) was rated A- until its downgrade on 2026-04-15 (A27).

JSON: {"rating": "A-"}

✅ R5 csv+ontology run 3 graded by code

A-. E10's downgrade A27 (2026-04-15) is the only later action, and E17 is the same entity, so it adds nothing.

JSON: {"rating": "A-"}

✅ R5 csv+ontology run 4 graded by code

A-. E10 (and E17, same LEI) was assigned A- (A26) and only downgraded to BBB+ on 2026-04-15 (A27).

JSON: {"rating": "A-"}

✅ R5 csv+ontology run 5 graded by code

A-. Halden Bank (E10, same LEI as E17) was rated A- (A26) until its downgrade on 2026-04-15 (A27).

JSON: {"rating": "A-"}

✅ R7 csv+neutral run 1 graded by code
