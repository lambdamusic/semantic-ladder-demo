Whose credit risk does a holder of the Halden Leasing 2028 notes take, and how is it rated?

Tests: Roles: the guarantor is the parent, not the ultimate parent.

Expected: risk_of = E10 rating = BBB+

✅ R1 csv run 1 graded by code

The guarantor, Halden Bank (E10), rated BBB+. I05 is issued by E11 and guaranteed by E10, whose rating is BBB+ after A27.

JSON: {"risk_of": "E10", "rating": "BBB+"}

✅ R1 csv run 2 graded by code

Halden Bank (E10), rated BBB+. I05 is guaranteed by E10, which was downgraded to BBB+ in A27.

JSON: {"risk_of": "E10", "rating": "BBB+"}

✅ R1 csv run 3 graded by code

The guarantor, Halden Bank (E10), rated BBB+ (A27). I05 is guaranteed by E10.

JSON: {"risk_of": "E10", "rating": "BBB+"}

✅ R1 csv run 4 graded by code

The guarantor, Halden Bank (E10), rated BBB+. I05 is guaranteed by E10, which was downgraded to BBB+ (A27). The note itself is also BBB+ (A29).

JSON: {"risk_of": "E10", "rating": "BBB+"}

JSON: {"risk_of": "E10", "rating": "BBB+"}

E10, Halden Bank, rated BBB+. E10 guarantees I05 and is the entity whose credit risk it takes, and its rating is BBB+ (A27, A29).

JSON: {"risk_of": "E10", "rating": "BBB+"}

Halden Bank (E10), the guarantor. The note is rated BBB+ (A29), matching E10's BBB+ (A27).
